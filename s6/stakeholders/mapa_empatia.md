# Mapatge de stakeholders — Accés a l'habitatge

## Problema detectat
Als joves els costa trobar un habitatge assequible perquè els preus pugen més que els sous.

## Resum del mapatge
| Grup d'interès | Tipus | Nivell d'afectació | Nivell d'influència |
|---|---|---|---|
| Joves de 18 a 30 anys amb sous baixos | directe | alt | baix |
| Famílies amb ingressos baixos o mitjans | directe | alt | baix |
| Propietaris particulars que viuen al pis o en tenen un de lloguer | directe | mitjà | mitjà |
| Grans propietaris i fons d'inversió (no viuen a l'habitatge) | indirecte | baix | alt |
| Ajuntament | influent | mitjà | alt |

## Perfil: Joves de 18 a 30 anys amb sous baixos
| Camp | Descripció |
|---|---|
| Descripció del perfil | Persones de 18 a 30 anys amb sous baixos que volen independitzar-se. |
| Com els afecta el problema | Gasten gran part del sou en lloguer i no poden estalviar. |
| Necessitats | Lloguers assequibles i ajuts. |
| Frustracions / pors | No poder marxar de casa dels pares i no tenir un futur estable. |
| Expectatives | Més habitatge públic i preus més baixos. |
| Capacitat d'adaptació | Compartir pis o viure lluny de la feina. |

## Perfil: Famílies amb ingressos baixos o mitjans
| Camp | Descripció |
|---|---|
| Descripció del perfil | Famílies amb fills que necessiten un habitatge estable i prou gran. |
| Com els afecta el problema | Gasten gran part dels ingressos en lloguer o hipoteca i els costa arribar a final de mes. |
| Necessitats | Lloguers assequibles i contractes llargs. |
| Frustracions / pors | Haver de canviar de barri o d'escola dels fills per preus. |
| Expectatives | Més habitatge públic i ajuts per a famílies. |
| Capacitat d'adaptació | Baixa: tenen poc marge per mudar-se o reduir despeses. |

## Perfil: Propietaris particulars
| Camp | Descripció |
|---|---|
| Descripció del perfil | Persones que tenen un o pocs pisos i els lloguen o hi viuen. |
| Com els afecta el problema | Les normes de preus poden reduir els seus ingressos. |
| Necessitats | Seguretat que cobraran el lloguer. |
| Frustracions / pors | Impagaments i canvis de normativa. |
| Expectatives | Ajuts fiscals per lloguers assequibles. |
| Capacitat d'adaptació | Alta: poden vendre o deixar de llogar. |

## Perfil: Grans propietaris i fons d'inversió
| Camp | Descripció |
|---|---|
| Descripció del perfil | Empreses i fons que tenen molts pisos i no hi viuen. |
| Com els afecta el problema | Poc, perquè només els afecta si es limiten els preus o la rendibilitat. |
| Necessitats | Rendibilitat i estabilitat legal per invertir. |
| Frustracions / pors | Topalls als preus i més impostos. |
| Expectatives | Normes clares i incentius per invertir. |
| Capacitat d'adaptació | Molt alta: poden moure la inversió a altres llocs o sectors. |

## Perfil: Ajuntament
| Camp | Descripció |
|---|---|
| Descripció del perfil | Administració local que gestiona el sòl i l'habitatge públic. |
| Com els afecta el problema | Pressió dels veïns i pèrdua de població jove. |
| Necessitats | Més pressupost i sòl per construir. |
| Frustracions / pors | Pocs recursos i tràmits lents. |
| Expectatives | Ajuda d'altres administracions. |
| Capacitat d'adaptació | Mitjana: pot crear habitatge públic, però depèn d'altres nivells. |
